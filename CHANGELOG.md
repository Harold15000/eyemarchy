# Changelog

## 1.0.0 · 2026-11-04

First public release.

- Four desktop cards: Clock, Agents, Now playing and System, each one in any slot of the screen.
- Agents: Claude Code (working, needs you, idle; background sessions with `claude attach`), Codex CLI and the ChatGPT app with thread titles, opencode, Gemini CLI, Grok, Antigravity, Hermes, Aider, Amp, Crush, Goose, Cursor Agent, Qwen Code, Copilot CLI, Droid, Kimi CLI, Pi, agents over SSH and your own by regex. Plan usage from Omarchy's Agents widget.
- Now playing for any MPRIS player, with source switching.
- System: CPU and temperature, RAM, GPU (NVIDIA and AMD), VRAM, disks, fans, battery and network. CPU and RAM unfold into the apps that use them, which can be closed.
- Keyboard navigation on an empty desktop, a shortcut to bring everything over your windows, and another to hide it.
- Settings panel, settings in `shell.json`, English and Spanish, demo mode.
